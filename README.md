# to-design

**Live site:** https://jstephens-create.github.io/to-design/

TO DESIGN: Planetary Responsibility is a single-page website by Jordan Stephens (i.c.stars, C60). It argues that designing things, systems and experiences is a planetary responsibility. It sets out five gifts (Empathy, Visual Imagination, Systems Thinking, Craft and Clear Communication), the career paths each one opens, a lab of practical actions, and a closing call to act.

The whole site lives in `index.html`. Design references are in `inspo/`. Fonts load from Google Fonts, so an internet connection is needed for the full effect.

## Workflow

1. Edit `index.html` in this folder.
2. Preview locally with the VS Code **Live Server** extension (right-click `index.html`, then "Open with Live Server"). It reloads on every save. Without the extension, run `python -m http.server 5500` here and open http://localhost:5500.
3. Commit and push to `main`.
4. GitHub Pages rebuilds from `main` / root automatically. Check the **Actions** tab for the "pages build and deployment" run; the live site updates a minute or two after it succeeds.
