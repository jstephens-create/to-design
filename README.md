# to-design

[TO DESIGN: Planetary Responsibility](../TO%20DESIGN_%20Planetary%20Responsibility.html) is a single-page website by Jordan Stephens (i.c.stars, C60). It argues that designing things, systems and experiences is a planetary responsibility. It sets out five gifts (Empathy, Visual Imagination, Systems Thinking, Craft and Clear Communication), the career paths each one opens, a lab of practical actions, and a closing call to act.

Open the HTML file in any browser to view it. The fonts and Three.js load from the web, so an internet connection is needed for the full effect.
